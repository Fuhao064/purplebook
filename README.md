# PurpleBook

小红书网页的页面精简与搜索扩展，适用于 Chrome / Microsoft Edge。

默认保留左侧栏，隐藏顶部导航、搜索区域和图片搜索悬浮入口。需要搜索时按 `/`，在页面原位置展开原生搜索框；再按 `/` 或 `Esc` 收起，关键词会保留，信息流始终可见。

> 当前版本 **0.3.8**，使用 Manifest V3，无需油猴。项目原名 PurplePurify。

## 选择版本

| 版本 | 默认效果 | 提供的设置 | 加载目录 |
| --- | --- | --- | --- |
| 完整版 | 显示侧栏，隐藏其他受控组件 | 页面精简、分组件隐藏、搜索增强、侧栏入口精简 | 仓库根目录 |
| 轻量版 | 只隐藏主页搜索框，其他元素沿用原生布局 | 隐藏主页搜索框、按 `/` 展开或收起 | 构建后生成的 `dist/home-search-only` |

同一时间只启用其中一个版本，避免两份扩展同时修改页面。两版设置随各自的扩展身份独立保存。

## 功能

| 功能 | 行为 |
| --- | --- |
| 页面精简 | 各组件隐藏的总开关；默认显示侧栏，隐藏其他受控组件 |
| 分组件隐藏 | 控制主页搜索框、顶部导航栏、侧栏、AI 横幅、吸顶搜索框、图片搜索悬浮按钮 |
| 页面搜索 | 按 / 原位展开或收起原生搜索框；Esc 也可收起，阅读内容保持可见 |
| 搜索结果导航 | 搜索结果页临时暂停页面精简，显示原生导航；返回首页自动恢复保存的设置 |
| 弹窗搜索 | 点击扩展图标输入关键词，在新标签页打开小红书搜索结果 |
| 选中文字搜索 | 网页上选中文字，右键选择“在小红书中搜索…” |
| 独立精简 | 可隐藏猜你想搜、AI 结果卡片、直播、AI 聊天、发布、通知、小红点和 RED 视频入口 |
| 设置同步 | 浏览器账户同步可用时，通过 `chrome.storage.sync` 同步设置 |

### 完整版默认布局

“页面精简”是下方组件隐藏的总开关，默认开启。分组件开关中，**打开表示隐藏，关闭表示显示**。

| 组件 | 默认状态 |
| --- | --- |
| 左侧栏 | 显示 |
| 主页搜索框 | 隐藏 |
| 顶部导航栏 | 隐藏 |
| 「问点点」AI 横幅 | 隐藏 |
| 吸顶搜索框 | 隐藏 |
| 「图片搜索」悬浮按钮 | 隐藏 |

“主页搜索框”等隐藏设置需要先开启“页面精简”。关闭总开关后，这些组件恢复显示，原选择会保留。侧栏隐藏时自动调整信息流居中；侧栏显示时保留原生布局和侧栏空间。

`/` 搜索、右键搜索和隐藏“猜你想搜”默认开启，其余独立精简项默认关闭。这些功能独立于“页面精简”总开关；关闭总开关时，`/` 仍可聚焦搜索，但收起后搜索区域会遵循组件的显示设置。

已有安装继续使用保存的设置。点击 **“恢复默认布局：显示侧栏，隐藏其他组件”**，可一键应用上述布局，不修改搜索增强和独立精简项。

## 安装与开始使用

1. 在 [GitHub 仓库](https://github.com/Fuhao064/purplebook) 点击 **Code → Download ZIP**，解压并保留文件夹；也可克隆仓库：

   ~~~sh
   git clone https://github.com/Fuhao064/purplebook.git
   ~~~

2. 打开 Chrome 的 `chrome://extensions` 或 Edge 的 `edge://extensions`。
3. 开启“开发者模式”，点击“加载已解压的扩展程序”，选择**仓库根目录，即直接包含 `manifest.json` 的目录**。
4. 打开或刷新 [小红书网页](https://www.xiaohongshu.com/explore)，将 PurpleBook 固定到工具栏。
5. 在页面非输入区域按 `/` 展开搜索，使用站点原生按钮提交；经典输入框也可按 Enter，新版 AI 搜索框沿用站点当前的提交方式。再次按 `/` 或 `Esc` 收起。

完整版可直接加载，安装无需 Node.js、npm 或构建。请保留安装目录，浏览器需要从该目录读取文件。

### 安装仅隐藏主页搜索框的轻量版

轻量版需要先生成安装目录，生成时使用 Node.js 18+，无需安装依赖：

~~~sh
node scripts/build-lite.mjs
~~~

在扩展管理页停用完整版，再选择“加载已解压的扩展程序”，加载 **`dist/home-search-only`**。生成后的整个目录可复制到其他电脑直接加载，无需再次构建。`variants/home-search-only` 是源码目录，请使用生成的安装目录加载。

轻量版只在 `/` 和 `/explore` 主页隐藏经典搜索框、新版 AI 搜索区域及其吸顶搜索框，搜索结果页与其他页面保持原生界面。两个开关默认开启，不附带弹窗搜索、右键搜索或其他精简功能。

### 快捷操作

| 操作 | 行为 |
| --- | --- |
| 页面非编辑区域按 `/` | 展开原生搜索框并聚焦 |
| 已展开的搜索框中按 `/` 或 `Esc` | 收起并保留关键词 |
| 评论、富文本等其他编辑区域输入 `/` | 正常输入，不触发搜索 |
| `Alt+Shift+P`（完整版） | 切换“页面精简”总开关 |

输入法合成期间以及 Ctrl / Alt / Meta 组合键不会触发斜杠搜索。搜索和登录沿用站点规则。

总开关快捷键为 `Alt+Shift+P`，可在 `chrome://extensions/shortcuts` 或 `edge://extensions/shortcuts` 修改。

## 更新与报错排查

1. Git 安装在原目录运行 `git pull --ff-only`；ZIP 安装将新版文件覆盖到原文件夹。
2. 使用轻量版时，重新执行 `node scripts/build-lite.mjs`。
3. 到扩展管理页点击“重新加载”，再**刷新所有已打开的小红书标签页**。

保留原安装目录可避免更换本地扩展身份而丢失设置。扩展重载不会自动替换已经打开的网页中的旧脚本。

0.3.8 已处理版本信息或设置接口缺失、失效时导致搜索脚本中断的问题。若错误页仍显示 `getManifest` 或 `Extension context invalidated`，先完成上面的更新步骤，再清空历史错误并重新触发操作，确认是否出现新记录。反馈时请附扩展版本、浏览器版本、操作步骤和新的错误内容，避开账号信息。

## 权限与数据

- `storage`：保存和同步开关设置。
- `contextMenus`（仅完整版）：选中文字右键搜索，默认可在任意网页使用。轻量版只申请 `storage`。
- 内容脚本仅注入 https://www.xiaohongshu.com/*，不请求读取全部标签页内容的权限。
- 代码不包含自建后端、埋点或搜索历史存储。搜索关键词会交给小红书处理，原生搜索仍遵循站点登录和访问要求。

## 开发预览

开发工具需要 Node.js 18+，无需安装依赖。运行回归检查、生成轻量版并启动预览：

~~~sh
node --test qa/extension-api.test.mjs
node scripts/build-lite.mjs
node qa/serve.mjs
~~~

| 预览地址 | 用途 |
| --- | --- |
| `http://127.0.0.1:8791/popup.html` | 完整版弹窗与默认布局设置 |
| `/explore`、`/explore?layout=ai` | 经典搜索框与新版 AI 搜索框 |
| `/explore?variant=lite` | 轻量版搜索交互 |
| `/lite/popup.html` | 轻量版弹窗 |
| `/layout` | 信息流布局与侧栏空间 |
| `/explore?api=missing-runtime` | 模拟版本接口缺失 |
| `/explore?variant=lite&layout=ai&api=stale-context` | 模拟扩展上下文失效 |

端口冲突时使用 `node qa/serve.mjs 0`，按终端实际地址访问。

预览使用模拟网页和浏览器 API，不能代替已加载扩展的小红书实页验证。

## 兼容性与致谢

功能依赖小红书网页 DOM 和 CSS 选择器，站点改版后可能需要更新。当前不提供 Firefox、Safari 或移动端版本。扩展不改变站点推荐算法或访问权限。

搜索增强和页面精简参考 [rednote-tweak](https://github.com/maxchang3/rednote-tweak)；早期 Electron 版本的布局与探针逻辑已适配为 MV3 内容脚本和 service worker。
