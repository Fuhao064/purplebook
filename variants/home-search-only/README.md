# PurpleBook Lite 0.3.8

仅隐藏小红书主页搜索框，保留导航、侧栏、推荐词、信息流与其他页面。

1. 在 Chrome / Edge 扩展管理页停用 PurpleBook 完整版，避免两版同时生效。
2. 开启开发者模式，选择“加载已解压的扩展程序”，加载本文件所在目录。
3. 刷新小红书主页，在非输入区域按 `/` 原位展开原生搜索框，再按 `/` 或 `Esc` 收起。

搜索框内的 `/` 用于收起，关键词会保留；评论和其他编辑框中的 `/` 正常输入。弹窗提供“隐藏主页搜索框”和“按 / 展开或收起”两个开关。

仅在 `/` 与 `/explore` 主页隐藏经典、新版 AI 与吸顶搜索区域，结果页正常显示搜索。搜索与登录沿用站点规则。

本目录由仓库中的 `node scripts/build-lite.mjs` 生成，可整体复制到其他电脑直接加载。修改源码后请重新生成，并在扩展管理页重新加载、刷新小红书页面。
