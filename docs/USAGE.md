# PurpleBook 使用指南

## 安装与更新

1. 从 [Fuhao064/purplebook](https://github.com/Fuhao064/purplebook) 点击 **Code → Download ZIP**，解压并保留文件夹；也可执行 `git clone https://github.com/Fuhao064/purplebook.git`。
2. 打开 `chrome://extensions`（Chrome）或 `edge://extensions`（Edge），开启开发者模式。
3. 点击“加载已解压的扩展程序”，选择**直接包含 `manifest.json` 的目录**。
4. 刷新已打开的小红书标签页，将 PurpleBook 固定到工具栏。

安装不需要 Node.js、npm、Electron 或油猴。请保留安装文件夹，浏览器需要从该目录读取文件。

更新时，Git 安装在原目录执行 `git pull --ff-only`；ZIP 安装将新版文件覆盖到原安装目录。然后在扩展管理页点击“重新加载”，再刷新小红书页面。

0.3.4 将 PurplePurify 改名为 PurpleBook，设置键和结构保持不变。在原目录更新可继续使用原设置；更换加载目录可能产生不同扩展 ID，设置不保证保留。避免同时启用新旧两份扩展。

## 页面布局

点击扩展图标进入弹窗。“分组件隐藏”中，**开关打开表示隐藏**，关闭表示显示。

| 控件 | 默认状态 | 行为 |
| --- | --- | --- |
| 纯净信息流 | 开启 | 控制五个组件隐藏和首页信息流居中 |
| 顶部导航栏 | 隐藏 | 顶部 logo、搜索和相关按钮区域 |
| 左侧边栏 | 隐藏 | 频道、登录入口及备案区域 |
| 「问点点」AI 横幅 | 隐藏 | 首页 AI 搜索区域 |
| 吸顶搜索框 | 隐藏 | 下滚后出现的顶部搜索区域 |
| 「图片搜索」悬浮按钮 | 隐藏 | 右下角图片搜索入口 |

修改即时生效。关闭总开关后，五个组件开关暂时不可操作，原选择会保留。居中补偿只在纯净模式开启、侧栏隐藏且页面存在对应网格时生效。

默认快捷键 `Alt+Shift+P` 切换总开关，可在 `chrome://extensions/shortcuts` 或 `edge://extensions/shortcuts` 修改。

## 三种搜索方式

### 页面按 `/`

在小红书页面非输入区域按 `/`，原生搜索框会临时居中并获得焦点。输入关键词，按 Enter 或使用原生搜索按钮；新版 AI 文本框沿用站点自己的提交方式。

按 `Esc` 或“返回页面”取消搜索，恢复原焦点、滚动位置和布局。临时视图不改写净化设置，路由变化、搜索节点被替换或关闭该功能时会退出。

评论框、搜索框和富文本等编辑区域中的 `/` 不会触发；Ctrl / Alt / Meta 组合键和输入法合成过程也不会触发。页面必须存在可交互的原生搜索框，搜索和登录要求由小红书处理。

### 弹窗搜索

点击扩展图标，在“搜索小红书”中输入关键词并提交，结果在新标签页打开，可从任意网页发起。空白关键词不会提交，中文、空格、`&`、`#` 等会按 URL 参数编码。

### 选中文字右键搜索

在任意网页选中文字，右键选择“在小红书中搜索…”。可通过“搜索增强 → 选中文字右键搜索”移除此菜单。

## 独立功能

| 设置 | 默认 |
| --- | --- |
| 按 / 打开纯净搜索 | 开启 |
| 选中文字右键搜索 | 开启 |
| 隐藏「猜你想搜」 | 开启 |
| 隐藏搜索结果 AI 卡片 | 关闭 |
| 隐藏直播、AI 聊天、发布、通知、通知小红点、RED 视频入口 | 各项均关闭 |

这些功能**独立于纯净信息流总开关**，在总开关关闭时仍按各自设置生效。显示侧栏后更容易观察单个入口隐藏的效果。

如需尽量恢复原网页，关闭总开关和所有隐藏项；完全停用时，在扩展管理页禁用扩展并刷新网页。

## 设置与卸载

设置保存在 `chrome.storage.sync`，实际跨设备同步取决于浏览器账户、同步服务和扩展身份，Chrome 与 Edge 之间不保证互通。

卸载时在扩展管理页移除 PurpleBook，再刷新小红书页面。移除扩展可能清除其设置。

## 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 找不到 manifest | 确认 ZIP 已解压，选中直接包含 `manifest.json` 的文件夹 |
| 首次安装后页面没有变化 | 刷新已有标签页，确认地址为 `https://www.xiaohongshu.com/` 下的页面 |
| `/` 没反应 | 检查功能开关、退出编辑区域，并确认原生搜索框已加载 |
| 搜索要求登录 | 遵循站点要求登录，扩展不绕过登录 |
| 总开关关闭后入口仍隐藏 | 检查独立的搜索增强和侧栏入口精简设置 |
| 快捷键无效 | 检查扩展快捷键页的键位和冲突；可改用弹窗 |
| 更新后仍显示旧名称或样式 | 重新加载扩展并刷新网页，检查是否重复安装旧版 |
| 显示侧栏后不再居中补偿 | 此为预期行为，显示侧栏时恢复站点布局 |
| 组件漏出或布局异常 | 暂时关闭相关开关，按开发说明排查站点选择器变化 |

反馈请附扩展版本、浏览器版本、页面类型、相关开关及复现步骤，截图避开账号和私人内容。
